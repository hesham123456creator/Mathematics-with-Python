# Differential Equations with Python

This folder contains Python programs for solving ordinary differential equations (ODEs) and boundary value problems.

## Topics Covered

### 1. Analytical Solutions
- First-order differential equations
- Second-order differential equations
- Nonhomogeneous differential equations

### 2. Numerical Methods
- Euler's method
- Fourth-order Runge-Kutta method (RK4)
- Adaptive Runge-Kutta method (RK45)
- Systems of ordinary differential equations

### 3. Boundary Value Problems
- Finite Difference Method
- Accuracy analysis
- SciPy solve_bvp()
- Comparison of numerical methods
- Nonlinear boundary value problems

### 4. Eigenvalue Problems
- Numerical eigenvalues
- Eigenvalue accuracy
- Comparison of eigenfunctions

## Python Libraries

- NumPy
- SymPy
- SciPy
- Matplotlib
